# PrepPulse product documentation

This directory contains the detailed guides for the PrepPulse local implementation.

1. [Product overview](product/PRODUCT_OVERVIEW.md) explains the problem PrepPulse addresses and its intended workflow.
2. [Architecture](product/ARCHITECTURE.md) explains the system boundaries, workflows and core design choices.
3. [Frontend](product/FRONTEND.md) describes the doctor, administrator and caregiver pages.
4. [Backend and data](product/BACKEND.md) documents OCR, APIs, persistence, identity and FHIR oriented preprocessing.
5. [AI and RAG](product/AI_AND_RAG.md) explains the review agents, evidence retrieval, charting and limitations.
6. [Setup](product/SETUP.md) explains local installation, database configuration and local or API model setup.
7. [Frontend integration handoff](FRONTEND_INTEGRATION_SPEC.md) contains detailed integration contracts.
8. [Stage 2 and 3 specification](STAGE_2_AND_3_SPECIFICATION.md) describes structured extraction and FHIR oriented preprocessing.

The root [README](../README.md) is the product overview and starting point.
